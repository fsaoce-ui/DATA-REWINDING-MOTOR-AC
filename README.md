# DATA REWINDING MOTOR AC

Aplikasi pencatatan teknis rewinding motor AC untuk Android.

## Fitur
- Penyimpanan offline di perangkat menggunakan SQLite.
- Pencarian berdasarkan judul dan isi catatan.
- Kategori: Umum, Data Motor, Lilitan / Winding, Pengukuran, Kerusakan, Perbaikan, Material.
- Favorit, tambah, edit, dan hapus catatan.

## Mengunduh APK
1. Buka tab **Actions** di repository GitHub.
2. Pilih workflow **Build APK Android**.
3. Tekan **Run workflow** bila belum berjalan otomatis.
4. Tunggu status **Success**.
5. Buka run yang berhasil dan unduh artifact **DATA-REWINDING-MOTOR-AC-APK**.
6. Ekstrak ZIP artifact, lalu pasang file `app-debug.apk` di Android.

Catatan disimpan secara lokal. Menghapus data aplikasi atau uninstall dapat menghapus catatan.
